# Kapsam ve ortak çalışma belgeleri

Bu dizin geliştirme sırasında hazırlanan kapsam ve mimari kararlarının anlık kopyasını içerir. Uygulanmış endpoint ve şemalar için projenin `contracts/openapi.json` dosyası; çalışan özellikler için ana README ve `docs/ARGON_HANDOFF.md` geçerlidir.

- `KOVAN_PILOT_KAPSAMI.md`: En güncel kullanıcı kapsamı; dört kız yurdu ve dört başlangıç adayı. Belge kontrolünün operasyon yöntemi henüz kararlaştırılmadı.
- `KOVAN_DOGRULAMA_YAKLASIMI.md`: Kimlikle üyelik ve otomasyon için seçenekler; gerçek entegrasyonun kurulmuş olduğu anlamına gelmez.
- `KOVAN_MVP_ORTAK_PLAN.md`: Sprint ve hedef mimari. İçindeki tüm hedefler uygulanmış değildir.
- `KOVAN_ARGON_BRIFI.md`: Arayüz/backend iş bölümü ve güncel teslim bağlantıları.
- `KOVAN_ARGON_V2_YANIT.md`: Önceki taslak üzerinde yapılan değerlendirme; tarihsel tartışma kaydıdır, güncel API sözleşmesi değildir.

Kodda yalnızca sentetik demo kimlikleri ve DEMO_TEST onayı var. Gerçek kimlik belgeleri, erişim kodları, oturumlar, veritabanı veya öğrenci konumları bu depoda bulunmaz.
